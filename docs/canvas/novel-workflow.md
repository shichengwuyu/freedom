# novel-workflow 剧本转视频成片工作流

novel-workflow v2 把"剧本→成片"这条链路建模成一条**多层、用户可见、可单步干预**的工作流。本文档说明用户如何用它把小说文本变成一段可下载的成片。

## 5 层流水线

工作流图横向显示 5 个层，每层有多个节点：

```
[输入] → [剧本] → [资产] → [镜头] → [后期]
                          ├ 视频   ├ BGM 选曲
                          ├ 配音   ├ 成片合成
                          └ 字幕   └ 导出
```

每个节点有 7 态状态机：

- **未启动** → **排队中** → **进行中** → （**成功** / **失败** / **跳过** / **已取消**）

## 启动模式

工作流顶部有两个按钮：

- **快速出片**：用所有节点默认参数一次跑完
- **自定义出片**：先调参数再启动
  - BGM 风格（古风 / 都市 / 紧张 / 温馨 / 伤感 / 史诗 / 欢快 / 悬疑）
  - 字幕样式（字体 / 字号 / 颜色 / 描边 / 位置）
  - 配音音色（成熟男声 / 温柔女声 / 等）
  - 是否烧字幕
  - 配音 / 字幕 / 合成是否全自动

底部 footer 还有"自动 / 手动"模式切换（默认自动）：

- **自动模式**：上游节点成功后下游节点自动启动
- **手动模式**：用户必须手动点每个节点的「开始」

## 单分镜操作

每个分镜卡片都有 3 个子节点（视频 / 配音 / 字幕）。配音卡和字幕卡可单独点：

- **▶ 试听配音**：浏览器播放该分镜的 mp3
- **重新生成配音**：改完音色 / 语速 / 文本后点此按钮，仅该分镜配音重跑
- **保存字幕 / 重做字幕**：手动编辑后点保存

## 关键 UX：成片回看 + 单层重做

合成成功后，novel 工作台切到「成片视图」——左播放器、右分镜列表、顶版本切换 tab。

每个分镜旁边有 4 个按钮：

- **重做视频** — 仅该分镜视频重跑
- **重做配音** — 仅该分镜配音重跑
- **重做字幕** — 仅该分镜字幕时间轴重算
- **重做风格** — v3 接 video style

整部成片顶部有 3 个按钮：

- **重烧字幕** — 仅跑 ffmpeg 烧字幕步骤（5 分钟内出新版，不重跑视频 / 配音）
- **重新合成** — 重跑 5 步合成（10-30 分钟）
- **重新配音** — 整部所有分镜配音重跑

每次重做会写一条 RerunRecord（version 自增 v1 / v2 / v3），可回滚到任意历史版本。

## 导出

合成成功后弹「导出」窗口：

- **下载 mp4** — 浏览器下载，文件名 = 项目名_时间戳.mp4
- **复制平台文案** — 抖音 / 小红书 / 视频号 三种风格文案，自动带 #标签
- **导出历史** — 列之前所有成功成片

v2 不做分享链接（token / 撤销），v3 再说。

## 漫剧一致性（series-asset-lock）

做漫剧 / 短剧的用户能在 novel 工作台顶部「主资产包」配置区：

1. 上传 N 个角色 + M 个场景 + K 个道具
2. 设一段「全局色调 prompt」（如"古风 3D 渲染 / 电影感 / 强光影 / 高细节"）
3. 锁定（点"锁定"按钮）

锁定后：

- 所有分镜视频生成的 prompt 自动追加「[全局色调 / 风格约束]」段
- 资产选择器只显示主资产包内的资产
- 同场景分镜共享同一张场景图

锁定可解锁（点"解锁"按钮）。已生成的视频节点**不被修改**——只有新跑的视频会按新规则。

## 失败 / 重试

- 单分镜 TTS 失败 → 该分镜降级为静音合成，节点整体仍记为"成功"
- 单分镜字幕失败 → 该分镜不烧字幕
- 单分镜视频缺失 → 该分镜跳过，任务日志记 warning
- BGM 未选 → 不混 BGM
- 合成任务 ffmpeg 失败 → 任务标"失败"，记 stderr 末 20 行到任务日志

任意节点失败都可以点"重试"按钮，使用最新项目状态重跑。

## 余额扣费

配音 TTS 调用前从用户余额扣费（默认 6 cents / 次），失败自动退款。其他节点（视频 / 字幕 / BGM / 合成）不单独扣费。

## 常见问题

- **为什么我的 mp4 只有音轨没有字幕？** — 检查"自定义出片 → 是否烧字幕"，或点击"重烧字幕"按钮。
- **改了字幕样式但没生效？** — 需要点"重烧字幕"按钮（改样式不自动重新跑合成）。
- **想做漫剧但每集角色变形？** — 用"主资产包"锁定后跑视频生成。
- **合成任务卡住？** — 点"停止"按钮取消，或查看任务日志最后几行 ffmpeg 输出。
