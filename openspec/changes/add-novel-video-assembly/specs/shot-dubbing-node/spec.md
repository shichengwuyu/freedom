## 用途

为 novel 工作流的「镜头配音节点」提供能力：对每个分镜按其「对白 / 旁白」文本调 TTS 模型生成 mp3 配音，挂在该镜头上供后续成片合成节点使用。配音失败时该镜头降级为静音，不阻塞整条流水线。

## ADDED Requirements

### Requirement: 按分镜自动配音

系统必须为工作流中的每个分镜（其「对白」或「旁白」非空）自动调 TTS 模型生成配音 mp3，挂在该分镜的配音字段上。

#### 场景：一键启动配音节点

- **当** 用户在 novel 工作流上点「镜头配音节点 → 开始」
- **那么** 系统遍历该项目下所有分镜，对「对白 / 旁白」非空的每个分镜调 TTS 模型，生成 mp3 并落库

#### 场景：分镜无文本时跳过

- **当** 某分镜的「对白」和「旁白」都为空
- **那么** 该分镜的配音字段保持空，节点对该分镜显示「跳过」徽标，不调 TTS

#### 场景：TTS 失败不阻塞其他分镜

- **当** 某个分镜的 TTS 调用在重试 2 次后仍失败
- **那么** 该分镜配音字段保持空，节点整体仍记为「成功」，合成时该镜头用静音兜底

### Requirement: 配音试听与重新生成

系统必须允许用户在 novel 工作台上对任意分镜的配音进行「试听」和「重新生成」。

#### 场景：试听配音

- **当** 用户点击某分镜配音卡上的「▶ 试听」按钮
- **那么** 浏览器播放该分镜对应的 mp3 配音

#### 场景：重新生成单条配音

- **当** 用户在配音卡上改完音色或语速，点「重新生成」
- **那么** 系统仅对该分镜重新调 TTS，不影响其他分镜

### Requirement: TTS 提供方可插拔

系统必须把 TTS 提供方抽象为单一接口，默认实现是 MiMo TTS；可换成火山 TTS / OpenAI TTS / ElevenLabs 等。

#### 场景：当前提供方不可用时给清晰错误

- **当** 配置的 TTS 提供方 HTTP 不可达
- **那么** 系统在 UI 上显示明确的中文错误信息，不静默 fallback 到另一个提供方

### Requirement: 配音音色与语速可调

系统必须允许用户为每个分镜选择 TTS 音色和调节语速；调节后该分镜的「重新生成」会用新参数调 TTS。

#### 场景：切换音色

- **当** 用户在某分镜的配音卡上下拉切换音色
- **那么** 该分镜的配音参数更新为新音色；下一次「重新生成」会生成新音色的配音

### Requirement: 配音持久化

每个分镜的配音数据（文本、音频 URL、时长 ms、音色 ID、语速、TTS 模型、生成状态）必须持久化到后端，刷新 / 切换页面 / 切换设备时能恢复。

#### 场景：刷新后配音仍在

- **当** 用户刷新 novel 工作台
- **那么** 所有分镜的配音卡仍显示「▶ 试听」按钮，点击可正常播放之前生成的 mp3

### Requirement: 配音扣费与退款

每个成功的 TTS 调用必须从用户余额扣费，失败的调用必须自动退款。

#### 场景：成功扣费

- **当** TTS 调用返回可用 mp3
- **那么** 用户余额按 TTS 模型定价扣减，并写入一条 type=`generation_consume` 的余额日志

#### 场景：失败退款

- **当** TTS 调用在重试 2 次后仍失败
- **那么** 已扣金额自动退回到用户余额
