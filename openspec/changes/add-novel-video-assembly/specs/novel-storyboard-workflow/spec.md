## 用途

把 novel 工作台后半段（剧本→成片）建模成一条「多层 + 用户可见 + 可单步干预」的工作流。本能力是其他 7 个 capability 的「编排底座」——它们都通过本能力的工作流层机制对外暴露。

## ADDED Requirements

### Requirement: 工作流分层

系统必须为「剧本→成片」整条链路定义一份分层的流水线。至少 5 个层（layer），每层可包含若干节点：

- **输入层**：小说文本 / 章节选择
- **剧本层**：分镜剧本
- **资产层**：角色 / 场景 / 道具
- **镜头层**：视频（已有）+ 配音 + 字幕（三个子节点）
- **后期层**：BGM 选曲 + 合成 + 导出（三个子节点）

#### 场景：用户从 UI 上看到全部 5 个层

- **当** 用户打开 novel 工作台
- **那么** 顶部工作流图横向显示 5 个层，每层显示当前状态徽标（未启动 / 排队中 / 进行中 / 成功 / 失败 / 跳过 / 已取消）

#### 场景：层内节点可折叠

- **当** 用户点开某层
- **那么** 展开显示该层的子节点（如镜头层展开后显示视频 / 配音 / 字幕三个子节点）

### Requirement: 节点统一状态机

系统的每个工作流节点必须遵循统一的状态机：`未启动 → 排队中 → 进行中 → （成功 / 失败 / 跳过 / 已取消）`；其中"失败 / 跳过"可被重试回到"排队中"。

#### 场景：节点启动进入排队态

- **当** 用户点击某节点的「开始」按钮
- **那么** 节点状态立即从「未启动」变成「排队中」，3 秒内进入「进行中」（取决于 worker 池空闲度）

#### 场景：节点成功完成

- **当** 节点对应的后端任务返回成功
- **那么** 节点状态变成「成功」，工作流图实时刷新

#### 场景：节点失败保持可重试

- **当** 节点对应的后端任务返回失败
- **那么** 节点状态变成「失败」，「重试」按钮亮起；下游节点保持「未启动」或「等待重试上游」态

#### 场景：用户主动停止节点

- **当** 用户点击某节点的「停止」按钮
- **那么** 节点状态变成「已取消」；后端 worker 收到 abort 信号，子进程被 kill

### Requirement: 节点依赖自动推进

工作流图必须支持"上游成功后自动启动下游"模式（也支持"手动单步跑"模式，用户可切换）。

#### 场景：自动模式下上游成功自动启动下游

- **当** 工作流跑在「自动模式」下，且上游节点变成「成功」
- **那么** 所有直接依赖它的下游节点自动从「未启动」变成「排队中」

#### 场景：上游失败时下游进入等待态

- **当** 工作流跑在「自动模式」下，且上游节点变成「失败」
- **那么** 下游节点保持「未启动」态，但 UI 上明确显示"等上游重试"

#### 场景：手动模式下用户逐个启动

- **当** 工作流跑在「手动模式」下
- **那么** 即使上游成功了，下游节点也不会自动启动；用户必须手动点每个节点的「开始」

### Requirement: 快速 / 自定义双模式

工作流必须支持两种启动模式：「快速模式」（用默认参数一次跑完）和「自定义模式」（用户先调参数再启动）。

#### 场景：快速模式启动

- **当** 用户点「快速出片」按钮
- **那么** 工作流用所有节点的默认参数（BGM = 古风 / 字幕样式 = 默认白底黑字 / 配音音色 = 成熟男声等）一次跑完

#### 场景：自定义模式启动

- **当** 用户点「自定义出片」按钮
- **那么** 系统先打开配置弹窗（背景音乐风格 / 字幕样式 / 目标时长 / 是否烧字幕 / 配音音色），用户保存后工作流才启动

### Requirement: 工作流刷新恢复

工作流任务的所有节点状态必须持久化到后端，刷新 / 切换页面 / 关闭后重开时自动恢复。

#### 场景：刷新后节点状态保留

- **当** 用户在工作流跑到一半时刷新页面
- **那么** 刷新回来后每个节点的状态徽标和进度数字与刷新前一致

#### 场景：多设备同步

- **当** 登录用户在设备 A 启动了工作流，换到设备 B 打开同一项目
- **那么** 设备 B 看到的工作流图与设备 A 完全一致

### Requirement: 工作流任务状态总览

novel 工作台顶部必须显示一个工作流「总体状态」徽标，聚合当前所有节点状态得出：「未启动 / 进行中 / 已完成 / 部分失败 / 已停止」。

#### 场景：总体状态根据节点聚合

- **当** 用户查看 novel 工作台顶部
- **那么** 总体状态徽标显示：所有节点都未启动 → 「未启动」；有节点进行中 → 「进行中」；所有节点都成功或跳过 → 「已完成」；有节点失败但其他都成功 → 「部分失败」；有节点被停止 → 「已停止」
