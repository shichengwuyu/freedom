## 用途

为 novel 工作流的「镜头字幕节点」提供能力：对每个分镜（shot）按其「对白 / 旁白」文本自动生成字幕时间轴，挂在该镜头上供成片合成节点烧录。字幕支持在合成前手动编辑，全局字幕样式（字体 / 颜色 / 位置等）在整部成片级别统一。

## ADDED Requirements

### Requirement: 按分镜自动生成字幕时间轴

系统必须为工作流中每个分镜（其「对白 / 旁白」非空）自动生成字幕时间轴，并把结果挂在该分镜的字幕字段上。

#### 场景：按字数线性切分字幕

- **当** 用户在 novel 工作流上点「镜头字幕节点 → 开始」
- **那么** 系统遍历每个分镜：取其「对白 / 旁白」文本，按标点切分成 N 行，按字数比例把行分配到该分镜的镜头视频时长内，落地为字幕时间轴

#### 场景：分镜无文本时跳过

- **当** 某分镜的「对白」和「旁白」都为空
- **那么** 该分镜的字幕字段保持空，节点对该分镜显示「跳过」徽标

#### 场景：分镜无视频时长时使用分镜默认时长

- **当** 某分镜没有显式的「镜头时长」字段
- **那么** 系统使用该分镜的默认时长（4 秒）作为字幕时间轴的总长度

### Requirement: 字幕手动编辑

系统必须允许用户对任意分镜的字幕时间轴手动编辑（改文字、拖动起止时间、新增 / 删除行）。

#### 场景：编辑某行字幕文字

- **当** 用户在字幕编辑器里改某行字幕的文字内容
- **那么** 修改立即保存，UI 实时反映

#### 场景：拖动某行字幕的起止时间

- **当** 用户在字幕编辑器的时间轴上拖动某行字幕的起点或终点
- **那么** 起止时间立即更新，保存到后端

#### 场景：新增一行字幕

- **当** 用户在字幕编辑器里点「新增行」并填入文字和起止时间
- **那么** 新行立即出现在时间轴上

#### 场景：删除一行字幕

- **当** 用户点某行字幕右侧的「删除」按钮
- **那么** 该行从时间轴上消失，保存到后端

#### 场景：编辑仅改数据不调模型

- **当** 用户编辑字幕
- **那么** 系统只更新字幕字段，不调任何 AI 模型；模型仅在「成片合成节点」实际烧录字幕时跑一次（ffmpeg 的 ass filter）

### Requirement: 全局字幕样式

用户必须能在 novel 工作台顶部为整部成片统一设置字幕样式（字体 / 字号 / 颜色 / 描边 / 位置）；样式应用于所有分镜。

#### 场景：修改全局字幕样式

- **当** 用户在 novel 工作台顶部「字幕样式」面板里改字体、颜色、位置等任意一项
- **那么** 修改立即保存；下一次「成片合成」按新样式烧录

#### 场景：默认样式

- **当** 用户从未改过字幕样式
- **那么** 系统使用默认样式：白字 + 黑描边 + 底部居中

### Requirement: 字幕持久化

每个分镜的字幕时间轴和全局字幕样式必须持久化到后端，刷新 / 切换页面 / 切换设备时能恢复。

#### 场景：刷新后字幕仍在

- **当** 用户刷新 novel 工作台
- **那么** 所有分镜的字幕编辑器仍展示之前编辑过的时间轴

#### 场景：登录用户跨设备同步

- **当** 登录用户在设备 A 编辑完所有字幕，切到设备 B
- **那么** 设备 B 看到的字幕时间轴和全局样式与设备 A 一致

### Requirement: 字幕节点状态与工作流集成

字幕节点必须遵循 novel-storyboard-workflow 定义的工作流节点状态机（未启动 / 排队中 / 进行中 / 成功 / 失败 / 跳过 / 已取消）和操作（开始 / 停止 / 重试）。

#### 场景：字幕节点作为工作流节点显示

- **当** 用户在 novel 工作流图上看到「镜头字幕节点」
- **那么** 它与其他工作流节点一样显示状态徽标，并暴露开始 / 停止 / 重试按钮

#### 场景：字幕节点依赖视频节点成功

- **当** 工作流跑在「自动模式」下，镜头视频节点仍是「未启动 / 进行中 / 失败」态
- **那么** 镜头字幕节点保持「未启动 / 等待重试上游」态，不启动
