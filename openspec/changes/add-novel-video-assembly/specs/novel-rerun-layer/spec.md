## 用途

为 novel 工作流的「成片回看 + 单层重做」提供能力：合成成功后用户进入"成片视图"——左播放器、右分镜列表、顶版本切换 tab；用户能针对单个分镜或整部成片，**只重跑某一层**（视频 / 配音 / 字幕 / 合成），不重跑其他层。这是 v2 的**核心 UX 补漏**。

## ADDED Requirements

### Requirement: 成片视图

合成任务成功后 novel 工作台必须能切换到「成片视图」。

#### 场景：切换到成片视图

- **当** 合成任务状态为「成功」
- **那么** UI 上展示「成片视图」入口；点开后左为播放器，右为分镜列表

#### 场景：分镜跳转播放

- **当** 用户在分镜列表点某分镜
- **那么** 播放器跳转到该分镜对应的时间段开始播放；分镜行高亮

### Requirement: 单分镜单层重做

成片视图中每个分镜必须能针对某一层重做（不重跑其他层）。

#### 场景：重做单分镜的配音

- **当** 用户在某分镜行点「重做配音」按钮
- **那么** 仅该分镜对应的配音子任务重跑；该分镜的视频、字幕、整部成片合成不会被触发（但用户在「整部成片」页面可触发合成）

#### 场景：重做单分镜的字幕

- **当** 用户在某分镜行点「重做字幕」按钮
- **那么** 仅该分镜的字幕时间轴重新生成；该分镜的视频、配音不动

#### 场景：重做单分镜的视频

- **当** 用户在某分镜行点「重做视频」按钮
- **那么** 仅该分镜对应的视频生成任务重跑；该分镜的配音、字幕、整部成片不动

### Requirement: 整部成片单层重做

成片视图顶部必须暴露整部级别的"重做某层"按钮。

#### 场景：重烧全片字幕

- **当** 用户改完全局字幕样式，点「重烧字幕」按钮
- **那么** 系统只跑 ffmpeg 的「烧字幕」步骤（步骤 ④），不重跑归一化 / 拼接 / 混音；新输出覆盖旧 URL

#### 场景：重新整部合成

- **当** 用户改了 BGM 或字幕样式，点「重新合成」按钮
- **那么** 系统跑完整的 5 步 ffmpeg 流水线；新输出覆盖旧 URL

#### 场景：重新整部配音

- **当** 用户换了 TTS 提供方或全局音色，点「重新配音」按钮
- **那么** 系统对所有分镜重跑配音（v1 capability shot-dubbing-node 行为），但**不**自动触发合成——用户需另点「重新合成」

### Requirement: 重做历史记录

每次"重做某层"必须记录到历史，**每层有独立版本号**。

#### 场景：查看分镜字幕版本

- **当** 用户在某分镜点开「字幕版本」下拉
- **那么** 展示该分镜字幕的所有历史版本（v1 / v2 / v3 ...），每条带时间戳

#### 场景：回滚到旧版本

- **当** 用户选某个旧版本（如 v2）并点「采用此版本」
- **那么** 该分镜字幕字段切回 v2 的内容；下次合成按 v2 烧录

### Requirement: 重做与工作流节点状态联动

单层重做必须复用 novel-storyboard-workflow 的节点状态机，**不能**绕开状态机直接改字段。

#### 场景：重做配音时节点状态变化

- **当** 用户点「重做配音」
- **那么** 配音节点对该分镜的状态变为「进行中」，完成后变「成功」；工作流图实时刷新
