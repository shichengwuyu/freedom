## 用途

为 novel 工作流的「BGM 选曲层」提供能力：从 6-8 个系统预设 BGM 中选一首应用到整部成片，或上传自定义 BGM。BGM 在合成时按"全局插入"模式混入。

本能力**不**引入 admin BGM 库管理——BGM 是 C 端娱乐逻辑（模板市场），Freedom 是创作者工具，系统预设 + 用户上传足够。

## ADDED Requirements

### Requirement: 系统预设 BGM 库

系统必须内置 6-8 个 BGM 预设，覆盖主流风格（古风 / 都市 / 紧张 / 温馨 / 伤感 / 史诗 / 欢快 / 悬疑）。预设 BGM 文件随 Docker 镜像一起打包，**用户无需下载**。

#### 场景：浏览预设 BGM

- **当** 用户点开 BGM 选曲面板
- **那么** 面板展示所有 6-8 个系统预设，每条显示风格标签 + 时长 + 「▶ 试听」按钮

#### 场景：试听预设 BGM

- **当** 用户点 BGM 列表中某条目的「▶ 试听」
- **那么** 浏览器播放该 BGM；点「停止」暂停

#### 场景：按风格筛选

- **当** 用户选风格筛选（如「古风」）
- **那么** BGM 列表只显示匹配该风格的预设

### Requirement: 用户上传自定义 BGM

用户必须能上传自己的 mp3 / wav 文件作为该项目的 BGM；上传后该 BGM 仅对该项目可见，不进入全局库。

#### 场景：上传自定义 BGM

- **当** 用户在 BGM 选曲面板里拖入或选一个 mp3 文件
- **那么** 文件落对象存储 `novel/bgm/custom/{projectId}/`，BGM 列表新增一项

#### 场景：限制 BGM 大小

- **当** 用户上传的音频文件超过 20MB
- **那么** 系统拒绝上传，给出明确错误

#### 场景：拒绝非音频文件

- **当** 用户上传非音频文件（如 zip）
- **那么** 系统拒绝上传，给出明确错误

### Requirement: 选定 BGM

用户必须能为该项目选一首 BGM，选中后该 BGM 标记为当前项目所用。

#### 场景：选用预设 BGM

- **当** 用户点某系统预设 BGM 的「选用」
- **那么** 该 BGM 标记为当前项目所用；UI 顶部展示 BGM 名称 + 试听按钮

#### 场景：选用自定义 BGM

- **当** 用户点自定义 BGM 的「选用」
- **那么** 同样标记为当前项目所用

#### 场景：取消 BGM

- **当** 用户点「不使用 BGM」
- **那么** 合成时不混 BGM；最终 mp4 音轨只有配音

### Requirement: BGM 音量 / 淡入 / 淡出

用户必须能为选中的 BGM 设置音量（相对配音）、淡入时长、淡出时长；参数保存到项目状态。

#### 场景：调节 BGM 音量 / 淡入 / 淡出

- **当** 用户拖动 BGM 音量 / 淡入 / 淡出滑杆
- **那么** 参数立即保存；下一次「合成」按新参数混音

### Requirement: BGM 状态持久化

每个项目的 BGM 选中状态 + 音量 / 淡入 / 淡出参数必须持久化到后端，刷新 / 切设备时恢复。

#### 场景：刷新后 BGM 仍在

- **当** 用户刷新 novel 工作台
- **那么** BGM 选曲面板仍显示当前选中的 BGM + 滑杆位置
