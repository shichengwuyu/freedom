## 用途

为 novel 工作流的「成片合成节点」提供能力：把项目下所有镜头视频 + 配音 + 字幕 + BGM + 可选片头 / 片尾，通过 ffmpeg 流水线合成一段最终 mp4，并支持下载、分享链接、平台发布文案。BGM 库归本节点下管理（admin 上传 / 用户按标签选曲）。

## ADDED Requirements

### Requirement: 一键合成成片

novel 工作流图上必须有一个「成片合成节点」，点「开始」后系统按以下顺序生成最终 mp4：归一化所有镜头视频 → 按分镜顺序拼接 → 混音（配音 + BGM） → 烧字幕 → 可选片头 / 片尾 → 输出最终 mp4。

#### 场景：启动合成任务

- **当** 用户点「成片合成节点 → 开始」
- **那么** 系统创建一个合成任务（状态：排队中），并立即交给 worker 池处理

#### 场景：合成按分镜顺序拼接

- **当** 合成任务执行时
- **那么** 镜头顺序与项目分镜剧本中的顺序一致（不是完成顺序）

#### 场景：分镜无视频时跳过

- **当** 某个分镜没有成功生成的镜头视频
- **那么** 合成任务跳过该分镜，并在任务日志里记一条 warning；最终 mp4 不含该分镜

#### 场景：分镜无配音时用静音

- **当** 某个分镜没有配音（空文本或 TTS 失败）
- **那么** 合成任务为该分镜生成与视频等长的静音音轨，与视频对齐

#### 场景：分镜无字幕时跳过烧字幕

- **当** 某个分镜没有字幕时间轴
- **那么** 合成任务不为该分镜烧字幕

#### 场景：未选 BGM 时不混 BGM

- **当** 用户没有为该项目选 BGM
- **那么** 合成任务不混 BGM 音轨；最终 mp4 音轨只有配音

### Requirement: 合成任务状态机

合成任务必须遵循 novel-storyboard-workflow 定义的工作流节点状态机：未启动 / 排队中 / 进行中 / 成功 / 失败 / 已取消。

#### 场景：合成进行中

- **当** worker 正在跑 ffmpeg
- **那么** 任务状态为「进行中」，UI 展示「当前步骤」（如「归一化镜头 3 / 8」）

#### 场景：合成成功

- **当** ffmpeg 进程退出码为 0 且输出文件已落对象存储
- **那么** 任务状态变成「成功」，记录输出 URL

#### 场景：合成失败

- **当** ffmpeg 进程退出码非 0
- **那么** 任务状态变成「失败」，记录 ffmpeg stderr 的最后 N 行到任务日志；用户能从 UI 上看到失败原因

#### 场景：用户停止合成

- **当** 用户在合成进行中点「停止」
- **那么** 任务状态变成「已取消」；worker 收到 abort 信号，ffmpeg 子进程被 kill；部分输出文件被清理

### Requirement: 合成进度可视化

合成任务必须展示分步骤的进度，便于用户判断任务在哪个阶段。

#### 场景：进度按 5 个步骤展示

- **当** 合成任务进行中
- **那么** UI 上显示 5 个步骤：① 归一化镜头视频 ② 拼接 ③ 混音 ④ 烧字幕 ⑤ 输出；当前步骤高亮，已完成步骤打勾

### Requirement: 合成可重试

合成任务失败后必须允许用户「重试」，重试时使用最新的项目状态（分镜、配音、字幕、BGM 配置）重新跑一遍 ffmpeg。

#### 场景：重试覆盖上次输出

- **当** 用户点失败任务的「重试」
- **那么** 系统创建新合成任务；新任务成功后覆盖之前的输出 URL；之前的 mp4 文件可被清理

### Requirement: BGM 选曲

用户必须能在 novel 工作台顶部为该项目选 BGM，并设置音量 / 淡入 / 淡出。

#### 场景：浏览 BGM 库

- **当** 用户点开 BGM 选曲面板
- **那么** 面板展示 admin 上传的所有 BGM，按用户选的标签筛选（如「古风」「都市」）

#### 场景：试听 BGM

- **当** 用户点 BGM 列表中某条目的「▶ 试听」
- **那么** 浏览器播放该 BGM；点「停止」暂停

#### 场景：选定 BGM

- **当** 用户点某 BGM 条目的「选用」
- **那么** 该 BGM 标记为当前项目所用；UI 顶部展示 BGM 名称 + 试听按钮

#### 场景：调节 BGM 音量 / 淡入 / 淡出

- **当** 用户拖动 BGM 音量 / 淡入 / 淡出滑杆
- **那么** 参数立即保存；下一次「合成」按新参数混音

### Requirement: 可选片头 / 片尾

合成节点必须支持可选的片头 / 片尾模板，admin 上传 / 用户选用。

#### 场景：选用片头

- **当** 用户在合成面板里点「选用片头」并选了一个片头模板
- **那么** 下一次「合成」时该片头会被加到 mp4 开头

#### 场景：不选片头

- **当** 用户没有选片头
- **那么** 合成任务不插入片头；mp4 开头直接是第一个镜头

### Requirement: 合成输出落库与下载

合成任务成功后必须把最终 mp4 落对象存储，记录输出 URL；用户能从 UI 上下载。

#### 场景：下载最终 mp4

- **当** 用户在合成任务成功的状态下点「下载」
- **那么** 浏览器开始下载 mp4 文件，文件名包含项目名和时间戳

#### 场景：刷新后输出仍在

- **当** 用户刷新 novel 工作台
- **那么** 之前的合成任务「成功」状态 + 输出 URL 仍在；下载 / 分享链接 / 复制文案按钮可用

### Requirement: 分享链接

合成任务成功后用户必须能生成一个分享链接，匿名用户可访问 mp4；分享链接有过期时间。

#### 场景：生成分享链接

- **当** 用户在导出弹窗里点「生成分享链接」
- **那么** 系统生成 16 字节随机 token + 记录过期时间（默认 30 天，可在 admin 配），返回完整 URL 给用户

#### 场景：匿名访问分享链接

- **当** 任何人在浏览器打开分享链接
- **那么** mp4 可直接播放；页面展示「由 Freedom 生成」小角标和项目 ID

#### 场景：分享链接过期

- **当** 当前时间超过分享链接的过期时间
- **那么** 访问返回 404；用户被告知链接已失效

#### 场景：撤销分享

- **当** 用户在导出弹窗里点某条分享链接的「撤销分享」
- **那么** 该分享链接立即失效，再访问返回 404；后台 mp4 文件可被清理

### Requirement: 平台发布文案

系统必须为用户生成一段适合抖音 / 小红书 / 视频号发布的文案（含项目标题 + 短描述 + 分享链接），供用户复制粘贴。

#### 场景：复制平台文案

- **当** 用户在导出弹窗里点「复制平台文案」
- **那么** 剪贴板得到一段文案：标题 + 一句话描述 + 分享链接 + 推荐标签

### Requirement: admin BGM 库管理

admin 后台必须支持 BGM 的上传、编辑标签、删除；删除时同步清理对象存储文件。

#### 场景：admin 上传 BGM

- **当** admin 在 BGM 管理页上传一个 mp3 文件 + 填标签（如「古风 / 紧张」）
- **那么** 文件落对象存储 `novel/bgm/`，元数据进 `bgm_tracks` 表；前端 BGM 选曲面板可立即看到

#### 场景：admin 删除 BGM

- **当** admin 删除某条 BGM
- **那么** 数据库行被删除，对象存储文件被同步删除；已经合成并使用此 BGM 的成片不受影响（已烧录在 mp4 中）

#### 场景：拒绝非音频文件

- **当** admin 上传了一个非音频文件（如 zip、txt）
- **那么** 系统拒绝上传，给出明确错误，不入库

#### 场景：限制 BGM 大小

- **当** admin 上传的音频文件超过 20MB
- **那么** 系统拒绝上传，给出明确错误，不入库
