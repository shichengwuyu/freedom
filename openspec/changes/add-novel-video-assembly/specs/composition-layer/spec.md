## 用途

为 novel 工作流的「成片合成层」提供能力：通过 ffmpeg 流水线把项目下所有镜头视频 + 配音 + 字幕 + BGM 合成为一段最终 mp4。合成任务有独立的状态机和可轮询的步骤进度。

## ADDED Requirements

### Requirement: 合成触发

系统必须在 novel 工作台后期层暴露「合成成片」操作，触发后端 ffmpeg 任务。

#### 场景：启动合成任务

- **当** 用户点「成片合成 → 开始」
- **那么** 系统创建合成任务（状态：排队中），并立即交给 worker 池处理

### Requirement: 合成步骤

合成任务必须按以下 5 个步骤顺序执行：① 归一化所有镜头视频 ② 按分镜顺序拼接 ③ 混音（配音 + BGM）④ 烧字幕 ⑤ 输出最终 mp4。

#### 场景：进度按 5 个步骤展示

- **当** 合成任务进行中
- **那么** UI 上显示 5 个步骤，当前步骤高亮，已完成步骤打勾；不显示单一百分比

### Requirement: 合成按分镜顺序拼接

合成任务必须按分镜剧本中分镜的声明顺序拼接所有镜头视频，而不是按完成时间排序。

#### 场景：合成按分镜顺序拼接

- **当** 合成任务执行时
- **那么** 镜头顺序与项目分镜剧本中的顺序一致（不是完成顺序）

#### 场景：分镜无视频时跳过

- **当** 某个分镜没有成功生成的镜头视频
- **那么** 合成任务跳过该分镜，并在任务日志里记一条 warning；最终 mp4 不含该分镜

#### 场景：分镜无配音时用静音

- **当** 某个分镜没有配音
- **那么** 合成任务为该分镜生成与视频等长的静音音轨，与视频对齐

#### 场景：未选 BGM 时不混 BGM

- **当** 用户没有为该项目选 BGM
- **那么** 合成任务不混 BGM 音轨；最终 mp4 音轨只有配音

#### 场景：分镜无字幕时不烧字幕

- **当** 某个分镜没有字幕时间轴
- **那么** 合成任务不为该分镜烧字幕

### Requirement: 合成任务状态机

合成任务必须遵循 novel-storyboard-workflow 定义的工作流节点状态机。

#### 场景：合成成功

- **当** ffmpeg 进程退出码为 0 且输出文件已落对象存储
- **那么** 任务状态变成「成功」，记录输出 URL

#### 场景：合成失败

- **当** ffmpeg 进程退出码非 0
- **那么** 任务状态变成「失败」，记录 ffmpeg stderr 的最后 N 行到任务日志

#### 场景：用户停止合成

- **当** 用户在合成进行中点「停止」
- **那么** 任务状态变成「已取消」；worker 收到 abort 信号，ffmpeg 子进程被 kill

### Requirement: 合成可重试

合成任务失败后必须允许用户「重试」，重试时使用最新的项目状态（分镜、配音、字幕、BGM 配置）重新跑一遍 ffmpeg。

#### 场景：重试覆盖上次输出

- **当** 用户点失败任务的「重试」
- **那么** 系统创建新合成任务；新任务成功后覆盖之前的输出 URL

### Requirement: 合成输出落库

合成任务成功后必须把最终 mp4 落对象存储，记录输出 URL 到任务记录。

#### 场景：刷新后输出仍在

- **当** 用户刷新 novel 工作台
- **那么** 之前的合成任务「成功」状态 + 输出 URL 仍在；下游 export-layer 可读取
