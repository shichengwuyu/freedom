## 用途

为 novel 项目的「剧集级资产锁定」提供能力：在项目级别（不是分镜级别）锁定一组资产作为「主资产包」，确保所有分镜视频生成从主资产包取参考图，**保证漫剧 / 短剧的世界观一致性**。

## ADDED Requirements

### Requirement: 主资产包定义

系统必须允许在 novel 项目级别定义一个「主资产包」，包含一组角色、一组场景、一组道具、一段全局色调 prompt。

#### 场景：创建主资产包

- **当** 用户在 novel 工作台顶部「主资产包」配置区里拖入资产 + 设全局色调 prompt
- **那么** 主资产包保存到项目；UI 显示「已锁定 N 角色 / N 场景 / N 道具」

#### 场景：未锁定的项目行为不变

- **当** 项目没有主资产包
- **那么** 视频生成按现有行为——分镜单独取资产，**不**强制一致性

### Requirement: 主资产包锁定时视频生成约束

主资产包一旦锁定，所有分镜视频生成必须从主资产包取参考图，**不能临时添加新资产**。

#### 场景：锁定后分镜只能选主资产包内资产

- **当** 主资产包已锁定，且用户在某分镜选择参考图
- **那么** 资产选择器**只显示**主资产包内的资产；不显示其他资产，**不**允许上传新资产到该分镜

#### 场景：锁定后跑视频生成

- **当** 视频节点跑某个分镜
- **那么** 参考图只从主资产包取；不调用其他资产

### Requirement: 主资产包跨分镜一致性约束

主资产包锁定后，系统必须保证相邻分镜的色调、镜头语言、角色朝向一致。

#### 场景：共享风格 reference

- **当** 主资产包包含一段全局色调 prompt
- **那么** 所有分镜视频生成的 prompt 都**自动追加**这段色调描述

#### 场景：同场景分镜共享场景图

- **当** 主资产包包含「教室」场景图
- **那么** 所有场景标注为「教室」的分镜**都**用同一张场景图作参考；**不**为不同分镜生成多张「教室」图

### Requirement: 主资产包可解锁

用户必须能解锁主资产包，解锁后恢复分镜自由选资产的灵活行为。

#### 场景：解锁主资产包

- **当** 用户在主资产包配置区点「解锁」
- **那么** 弹确认框；确认后主资产包标记为「未锁定」；视频生成恢复分镜自由选资产

#### 场景：解锁后历史分镜不变

- **当** 用户解锁主资产包
- **那么** 已经生成的视频节点**不被修改**；只是后续重跑会按新规则

### Requirement: 主资产包持久化

主资产包数据（角色 / 场景 / 道具列表 + 全局色调 prompt + 锁定状态）必须持久化到项目级别，刷新 / 切设备时恢复。

#### 场景：刷新后主资产包仍在

- **当** 用户刷新 novel 工作台
- **那么** 主资产包配置区仍展示之前锁定的资产 + 色调 prompt

#### 场景：跨设备同步

- **当** 登录用户在设备 A 锁定了主资产包，切到设备 B
- **那么** 设备 B 看到同样的主资产包 + 锁定状态
