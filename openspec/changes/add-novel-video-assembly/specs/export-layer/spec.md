## 用途

为 novel 工作流的「导出层」提供能力：合成成功后用户可下载最终 mp4，并获取适合抖音 / 小红书 / 视频号发布的文案。

**v2 不做分享链接 / token / 撤销**——这些放 v3。本层只做"下载 + 平台文案"。

## ADDED Requirements

### Requirement: 直接 mp4 下载

合成任务成功后用户必须能从 UI 上下到最终 mp4。

#### 场景：下载按钮工作

- **当** 用户在合成任务成功的状态下点「下载」
- **那么** 浏览器开始下载 mp4 文件，文件名包含项目名和时间戳

#### 场景：刷新后下载仍可用

- **当** 用户刷新 novel 工作台
- **那么** 之前的合成任务「成功」状态 + 下载按钮仍在

### Requirement: 平台发布文案

系统必须为用户生成一段适合抖音 / 小红书 / 视频号发布的文案（含项目标题 + 短描述 + 短视频推荐标签），供用户复制粘贴。

#### 场景：复制平台文案

- **当** 用户在导出弹窗里点「复制平台文案」
- **那么** 剪贴板得到一段文案：标题 + 一句话描述 + 推荐标签

#### 场景：自定义文案

- **当** 用户在文案编辑框里改字
- **那么** 修改立即保存到本地状态（不需要回写后端）

### Requirement: 导出元数据

每次成功的合成任务在 export-layer 必须有可读的元数据（项目标题、合成时间、时长、文件大小、所用 BGM / 字幕样式）。

#### 场景：展示成片元数据

- **当** 用户在导出弹窗里查看
- **那么** 弹窗展示：项目名 / 合成时间 / 视频时长 / 文件大小 / BGM 名称 / 字幕样式
